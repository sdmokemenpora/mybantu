# Ponytail Guidelines for MyBantu

## Core Tenets
1. **Evidence-Based Changes**: Only modify or fix code based on verifiable, explicit lines of code. No speculative abstractions.
2. **YAGNI (You Aren't Gonna Need It)**: Do not create unused microservices, bloated packages, or redundant methods.
3. **Eliminate Dead Code**: Remove redundant duplicate controller methods or dead relationships.
4. **Impact Mapping**: Before changing any query or route, inspect all callers, views, and database schemas.
5. **Transparent Trade-offs**: Keep solutions straightforward and native to the existing Laravel + Blade + Tailwind stack.
