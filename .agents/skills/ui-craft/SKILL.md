# UI Craft Guidelines for MyBantu

## Craft Principles
1. **State Completeness**: Handle default, hover, active, focus-visible, disabled, loading, and empty states gracefully.
2. **Accessible Interaction**: Provide clear contrast, legible touch targets (min 44px on mobile), and accessible form controls.
3. **Micro-Interactions**: Subtle transitions (`transition duration-150 ease-in-out`), smooth scaling on cards (`hover:-translate-y-0.5`), and refined borders.
4. **Data Presentation**: Clean tabular presentation, readable status badges with semantic colors (e.g. green for confirmed/paid, amber for pending, slate for inactive).
5. **Mobile Responsiveness**: Comprehensive responsive design including collapsible mobile navigation and responsive tables with card alternatives.
