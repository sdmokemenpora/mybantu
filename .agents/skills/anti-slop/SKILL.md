# Anti-Slop Guidelines for MyBantu

## Core Rules
1. **No Dummy/Slop Placeholders**: Never use placeholder="Value", "Lorem ipsum", or mock names like "Joko" without fallback handling.
2. **Distinctive Visuals**: Avoid generic AI purple gradients, uniform 3-card templates, and repetitive hero banners.
3. **Authentic Microcopy**: Use clear, natural Indonesian terminology fitting a domestic service marketplace (Asisten Rumah Tangga, Mitra ART, Rekening Bersama, Garansi Kerja).
4. **Context-Rich Details**: Every form input, helper text, and button must have descriptive labels and intuitive placeholders.
